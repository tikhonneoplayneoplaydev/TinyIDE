WASM-плагины TinyIDE

Один .wasm-модуль работает и в десктоп-версии (интерпретатор wasmi), и в браузере (нативный WebAssembly). Безопасно, быстро, кроссплатформенно.

📦 Как установить

ШАГ 1

Собери плагин

Rust или любой язык в WASM (wasm32-unknown-unknown). Папка с plugin.toml и plugin.wasm.

ШАГ 2

Установи в TinyIDE

Панель Plugins → «Установить из папки…» и выбери папку плагина.

ШАГ 3

Готово

Плагин загрузится (wasmi в десктопе / нативный WASM в браузере) и включится. Отключить/включить можно в любой момент.

🛠 Plugin API

Плагин экспортирует три функции и общается JSON-командами через tinyide_handle.

// plugin.wasm exports (C ABI) alloc(len: u32) -> ptr dealloc(ptr: u32, len: u32) tinyide_handle(cmd_ptr, cmd_len, out_ptr, out_cap) -> len // команды (JSON): { "cmd": "init" } // -> {languages, commands} { "cmd": "completions", "word": "pri" } { "cmd": "diagnose", "source": "..." } { "cmd": "transpile", "source": "..." } { "cmd": "outline", "source": "..." }
